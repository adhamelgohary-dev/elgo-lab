# Creating original learning content

Use only material you own or are allowed to publish. Review generated questions for accuracy before importing them.

Example prompt:

> Write six original introductory computing questions with four options each. Give each question a unique id, a question string, options as objects with id and text, and a correctOptionId. Include explanation in English and explanationArabic in Arabic. Return a JSON array. Avoid copying published exam questions and distribute correct answers across A-D.

Open the Admin Portal, select the target course, and import a draft. Check question wording, answer keys, explanations, images and ranked grading before publishing. The bundled demo is an example of the canonical JSON format.
